APM-LDPC のサイクルを合成関数で調べる

パリティ検査行列 H = (fij) をブロック行列とみなし、各ブロックを fij(x) = aijx + bij (mod P) で与えます。指定した長さ ℓ の block cycle を列挙し、その合成関数 fc の固定点から Tanner グラフ上のサイクルの有無を確認できます。

1. パラメータの設定



（行数 ≤ 6, 列数 ≤ 8 程度を推奨）

2. サイクル探索条件


各ブロックはアフィン置換 f(x) = a x + b (mod P) として扱われます（gcd(a, P) = 1 が必須）。block cycle の合成関数 fc の固定点が存在する ⇔ 対応する Tanner サイクルが存在します。
