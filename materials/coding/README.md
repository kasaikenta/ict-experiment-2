# 符号理論：課題3・4の配付ファイル

課題PDFで指定された入力ファイルを使用してください。実装するプログラムの仕様と解答形式は課題PDFを参照してください。

## 課題3

- `vec.txt`：ハミング距離
- `code.txt`：符号の最小距離
- `r.txt`：最小距離復号
- `linearcode.txt`：線形符号
- `dual.txt`：符号と双対符号の重み分布

## 課題4

- `linear_equation_Fp.txt`：素体上の連立一次方程式
- `poly.txt`：多項式の演算
- `linear_equation_F256.txt`：拡大体上の連立一次方程式
- `RS256_encode_example.txt`、`RS256_decode_example.txt`：課題で参照する入出力例
- `RS256_encode_problem.txt`、`RS256_decode_problem.txt`：RS符号の課題入力

プログラムとレポートは、指定された授業システムに電子データとして提出してください。
